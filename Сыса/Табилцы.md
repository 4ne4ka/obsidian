# Полная таблица функций MPI с параметрами, назначением и особенностями

---

## 1. Инициализация и завершение

| Функция | Параметры | Что делает | Когда используется | Особенности |
|---------|-----------|------------|-------------------|-------------|
| **MPI_Init** | `int* argc, char*** argv` | Инициализирует библиотеку MPI | Первый вызов MPI в программе | Должна быть вызвана **первой** (можно объявлять переменные до). Вызывается **один раз**. Не обязательно из `main`. Передаются адреса `argc` и `argv` из `main` |
| **MPI_Finalize** | нет | Завершает работу с MPI | Последний вызов MPI | Должна быть вызвана **последней**. Вызывается **один раз**. После неё нельзя использовать функции MPI (кроме некоторых). Можно выполнять обычный код (освобождение памяти, закрытие файлов) |
| **MPI_Abort** | `MPI_Comm comm, int errorcode` | Досрочное завершение всех процессов | При критической ошибке | Аналог `exit()`. Завершает **все** процессы коммуникатора. Код ошибки возвращается в среду запуска |
| **MPI_Wtime** | нет | Возвращает время в секундах (double) | Замер времени | **Не имеет параметров**. Возвращает `double`. Разница двух вызовов = время в секундах. Независима от платформы |
| **MPI_Wtick** | нет | Возвращает точность таймера (double) | Узнать точность замеров | **Не имеет параметров**. Обычно возвращает 1 микросекунду (1e-6) |

## 2. Информация о процессах и коммуникаторах

| Функция | Параметры | Что делает | Когда используется | Особенности |
|---------|-----------|------------|-------------------|-------------|
| **MPI_Comm_size** | `MPI_Comm comm, int* size` | Возвращает количество процессов в коммуникаторе | Узнать общее число процессов | Если `comm = MPI_COMM_WORLD` — общее число процессов. Если другой — число процессов в нём |
| **MPI_Comm_rank** | `MPI_Comm comm, int* rank` | Возвращает ранг процесса в коммуникаторе | Узнать свой номер | Ранг от 0 до size-1. Уникален в рамках коммуникатора. Не меняется |
| **MPI_Comm_group** | `MPI_Comm comm, MPI_Group* group` | Выделяет группу из коммуникатора | Для работы с группами | Группа — совокупность рангов. Можно создавать новые группы |
| **MPI_Group_incl** | `MPI_Group oldgroup, int n, int* ranks, MPI_Group* newgroup` | Создаёт новую группу, включая указанные ранги | Для создания подгрупп | Ранги указываются в массиве. Порядок сохраняется |
| **MPI_Group_excl** | `MPI_Group oldgroup, int n, int* ranks, MPI_Group* newgroup` | Создаёт новую группу, исключая указанные ранги | Для создания подгрупп | Исключаются указанные ранги, остальные включаются |
| **MPI_Group_free** | `MPI_Group* group` | Освобождает группу | После использования группы | Хороший тон — освобождать |
| **MPI_Comm_dup** | `MPI_Comm oldcomm, MPI_Comm* newcomm` | Дублирует коммуникатор | Для создания копии | Новый контекст. Безопасно для коллективных операций |
| **MPI_Comm_create** | `MPI_Comm oldcomm, MPI_Group group, MPI_Comm* newcomm` | Создаёт коммуникатор из группы | Для создания подкоммуникатора | Все процессы группы должны вызвать. У каждого свой newcomm |
| **MPI_Comm_split** | `MPI_Comm oldcomm, int color, int key, MPI_Comm* newcomm` | Разбивает коммуникатор на несколько по цветам | Для создания подкоммуникаторов | Процессы с одинаковым `color` попадут в один коммуникатор. `key` — порядок. Если `color = MPI_UNDEFINED` — процесс не войдёт |
| **MPI_Comm_free** | `MPI_Comm* comm` | Освобождает коммуникатор | После использования | Нельзя освобождать `MPI_COMM_WORLD` |

## 3. Парные операции (Point-to-Point)

### 3.1. Отправка

| Функция | Параметры | Что делает | Когда используется | Особенности |
|---------|-----------|------------|-------------------|-------------|
| **MPI_Send** | `void* buf, int count, MPI_Datatype datatype, int dest, int tag, MPI_Comm comm` | Стандартная блокирующая отправка | Обычная отправка | Завершается, когда данные **скопированы во внутренний буфер** MPI. После завершения буфер можно менять. **Не гарантирует** доставку. Самый частый режим |
| **MPI_Ssend** | `void* buf, int count, MPI_Datatype datatype, int dest, int tag, MPI_Comm comm` | Синхронная блокирующая отправка | Когда нужна надёжность | Завершается, когда получатель **начал приём** (вызвал `MPI_Recv`). **Наибольшие гарантии**. **Самый медленный**. Рекомендован для больших объёмов |
| **MPI_Rsend** | `void* buf, int count, MPI_Datatype datatype, int dest, int tag, MPI_Comm comm` | Отправка «по готовности» | Когда получатель точно готов | Требует, чтобы `MPI_Recv` был **уже вызван**. **Самый быстрый**. Сложно реализовать. Нужна гарантия (например, `MPI_Barrier`) |
| **MPI_Bsend** | `void* buf, int count, MPI_Datatype datatype, int dest, int tag, MPI_Comm comm` | Буферизованная отправка | Когда нужен свой буфер | Требует `MPI_Buffer_attach`. Данные хранятся в **своём** буфере. После — `MPI_Buffer_detach` |
| **MPI_Isend** | `void* buf, int count, MPI_Datatype datatype, int dest, int tag, MPI_Comm comm, MPI_Request* request` | Неблокирующая отправка | Для совмещения с вычислениями | Немедленно возвращает `request`. Операция выполняется асинхронно. Нужен `MPI_Wait`/`MPI_Test` |
| **MPI_Issend** | `void* buf, int count, MPI_Datatype datatype, int dest, int tag, MPI_Comm comm, MPI_Request* request` | Неблокирующая синхронная | Для совмещения с вычислениями | Аналог `MPI_Ssend`, но неблокирующий |
| **MPI_Ibsend** | `void* buf, int count, MPI_Datatype datatype, int dest, int tag, MPI_Comm comm, MPI_Request* request` | Неблокирующая буферизованная | Для совмещения | Аналог `MPI_Bsend`, но неблокирующий |
| **MPI_Irsend** | `void* buf, int count, MPI_Datatype datatype, int dest, int tag, MPI_Comm comm, MPI_Request* request` | Неблокирующая «по готовности» | Для совмещения | Аналог `MPI_Rsend`, но неблокирующий |

### 3.2. Приём

| Функция | Параметры | Что делает | Когда используется | Особенности |
|---------|-----------|------------|-------------------|-------------|
| **MPI_Recv** | `void* buf, int count, MPI_Datatype datatype, int source, int tag, MPI_Comm comm, MPI_Status* status` | Блокирующий приём | Обычный приём | **Блокирующая** — ждёт данные. Если source/tag неверный — **висит**. `MPI_ANY_SOURCE` — от любого. `MPI_ANY_TAG` — с любым тегом. Из `status` можно узнать source, tag, count |
| **MPI_Irecv** | `void* buf, int count, MPI_Datatype datatype, int source, int tag, MPI_Comm comm, MPI_Request* request` | Неблокирующий приём | Для совмещения с вычислениями | Немедленно возвращает `request`. Нужен `MPI_Wait`/`MPI_Test` |

### 3.3. Обмен

| Функция | Параметры | Что делает | Когда используется | Особенности |
|---------|-----------|------------|-------------------|-------------|
| **MPI_Sendrecv** | `void* sendbuf, int sendcount, MPI_Datatype sendtype, int dest, int sendtag, void* recvbuf, int recvcount, MPI_Datatype recvtype, int source, int recvtag, MPI_Comm comm, MPI_Status* status` | Обмен между двумя процессами | Когда нужен обмен | **Блокирующая**. Избегает **дедлока**. Два буфера (send и recv) |
| **MPI_Sendrecv_replace** | `void* buf, int count, MPI_Datatype datatype, int dest, int sendtag, int source, int recvtag, MPI_Comm comm, MPI_Status* status` | Обмен в одном буфере | Когда старые данные не нужны | **Один буфер**. Экономия памяти. Заменяет содержимое принятыми данными |

### 3.4. Управление неблокирующими операциями

| Функция          | Параметры                                                                               | Что делает                      | Когда используется       | Особенности                                                                    |
| ---------------- | --------------------------------------------------------------------------------------- | ------------------------------- | ------------------------ | ------------------------------------------------------------------------------ |
| **MPI_Wait**     | `MPI_Request* request, MPI_Status* status`                                              | Блокирующее ожидание завершения | Когда нужно дождаться    | Ждёт, пока операция не завершится. После — `request` можно использовать снова  |
| **MPI_Test**     | `MPI_Request* request, int* flag, MPI_Status* status`                                   | Неблокирующая проверка          | Когда нужно проверить    | `flag = 0` — не завершена. `flag != 0` — завершена. Сразу возвращает результат |
| **MPI_Waitall**  | `int count, MPI_Request* requests, MPI_Status* statuses`                                | Ожидание всех операций          | Когда несколько операций | Ждёт завершения **всех**                                                       |
| **MPI_Testall**  | `int count, MPI_Request* requests, int* flag, MPI_Status* statuses`                     | Проверка всех операций          | Когда несколько операций | `flag != 0` — все завершены                                                    |
| **MPI_Waitany**  | `int count, MPI_Request* requests, int* index, MPI_Status* status`                      | Ожидание любой из операций      | Когда нужна любая        | Возвращает `index` завершённой                                                 |
| **MPI_Testany**  | `int count, MPI_Request* requests, int* index, int* flag, MPI_Status* status`           | Проверка любой                  | Когда нужна любая        | —                                                                              |
| **MPI_Waitsome** | `int incount, MPI_Request* requests, int* outcount, int* indices, MPI_Status* statuses` | Ожидание некоторых              | Когда нужно несколько    | —                                                                              |
| **MPI_Testsome** | `int incount, MPI_Request* requests, int* outcount, int* indices, MPI_Status* statuses` | Проверка некоторых              | Когда нужно несколько    | —                                                                              |

### 3.5. Буферизация

| Функция | Параметры | Что делает | Когда используется | Особенности |
|---------|-----------|------------|-------------------|-------------|
| **MPI_Buffer_attach** | `void* buffer, int size` | Регистрирует буфер для `MPI_Bsend` | Перед `MPI_Bsend` | Буфер выделяется вручную |
| **MPI_Buffer_detach** | `void* buffer, int* size` | Освобождает буфер | После `MPI_Bsend` | Хороший тон — освобождать |

## 4. Коллективные операции

| Функция | Параметры | Что делает | Когда используется | Особенности |
|---------|-----------|------------|-------------------|-------------|
| **MPI_Bcast** | `void* buf, int count, MPI_Datatype datatype, int root, MPI_Comm comm` | Рассылка копии всем | Когда один процесс имеет данные для всех | **Все** процессы вызывают. У root буфер заполнен, у остальных — выделен. **Самая частая**. Реализация — дерево (быстрее цикла) |
| **MPI_Reduce** | `void* sendbuf, void* recvbuf, int count, MPI_Datatype datatype, MPI_Op op, int root, MPI_Comm comm` | Сбор + операция | Суммирование, минимум, максимум | **Все** вызывают. Результат у **root**. `op` — операция. `count`, `datatype`, `op`, `root`, `comm` — одинаковые у всех |
| **MPI_Allreduce** | `void* sendbuf, void* recvbuf, int count, MPI_Datatype datatype, MPI_Op op, MPI_Comm comm` | Сбор + операция на всех | Когда результат нужен всем | Нет `root`. Результат у **всех**. Альтернатива: `MPI_Reduce` + `MPI_Bcast` |
| **MPI_Scatter** | `void* sendbuf, int sendcount, MPI_Datatype sendtype, void* recvbuf, int recvcount, MPI_Datatype recvtype, int root, MPI_Comm comm` | Распределение частей | Когда root имеет массив для распределения | `sendcount` — **размер порции** для одного процесса. Общий размер = `sendcount * size`. **Делится нацело!** Каждому — непрерывный блок |
| **MPI_Scatterv** | `void* sendbuf, int* sendcounts, int* displs, MPI_Datatype sendtype, void* recvbuf, int recvcount, MPI_Datatype recvtype, int root, MPI_Comm comm` | Распределение с разными порциями | Когда не делится нацело или порции разные | `sendcounts` — массив. `displs` — массив смещений. **Неравномерное** распределение |
| **MPI_Gather** | `void* sendbuf, int sendcount, MPI_Datatype sendtype, void* recvbuf, int recvcount, MPI_Datatype recvtype, int root, MPI_Comm comm` | Сбор данных | Когда нужно собрать данные на root | `recvcount` — сколько **от каждого**. Размер recvbuf = `recvcount * size`. Данные раскладываются **по рангам** |
| **MPI_Gatherv** | `void* sendbuf, int sendcount, MPI_Datatype sendtype, void* recvbuf, int* recvcounts, int* displs, MPI_Datatype recvtype, int root, MPI_Comm comm` | Сбор с разными порциями | Когда от разных процессов разное количество | `recvcounts` — массив. `displs` — массив. Каждый указывает **свой** sendcount |
| **MPI_Allgather** | `void* sendbuf, int sendcount, MPI_Datatype sendtype, void* recvbuf, int recvcount, MPI_Datatype recvtype, MPI_Comm comm` | Сбор на всех | Когда результат нужен всем | Нет `root`. Результат у **всех** |
| **MPI_Allgatherv** | `void* sendbuf, int sendcount, MPI_Datatype sendtype, void* recvbuf, int* recvcounts, int* displs, MPI_Datatype recvtype, MPI_Comm comm` | Сбор с разными порциями на всех | Когда результат нужен всем и порции разные | Нет `root`. `recvcounts`, `displs` — массивы |
| **MPI_Alltoall** | `void* sendbuf, int sendcount, MPI_Datatype sendtype, void* recvbuf, int recvcount, MPI_Datatype recvtype, MPI_Comm comm` | Обмен всех со всеми | Когда каждый отправляет каждому | **Транспонирование** матрицы данных. Каждый отправляет **разные** данные каждому |
| **MPI_Alltoallv** | `void* sendbuf, int* sendcounts, int* sdispls, MPI_Datatype sendtype, void* recvbuf, int* recvcounts, int* rdispls, MPI_Datatype recvtype, MPI_Comm comm` | Обмен всех со всеми с разными порциями | Когда порции разные | Массивы `sendcounts`, `sdispls`, `recvcounts`, `rdispls` |
| **MPI_Barrier** | `MPI_Comm comm` | Синхронизация | Точка синхронизации | **Все** ждут друг друга. Применяется редко |
| **MPI_Ibcast** | `void* buf, int count, MPI_Datatype datatype, int root, MPI_Comm comm, MPI_Request* request` | Неблокирующая рассылка | Для совмещения | Немедленно возвращает `request` |
| **MPI_Ireduce** | `void* sendbuf, void* recvbuf, int count, MPI_Datatype datatype, MPI_Op op, int root, MPI_Comm comm, MPI_Request* request` | Неблокирующая редукция | Для совмещения | Результат может **не совпадать** с блокирующим (порядок операций) |
| **MPI_Iscatter** | `void* sendbuf, int sendcount, MPI_Datatype sendtype, void* recvbuf, int recvcount, MPI_Datatype recvtype, int root, MPI_Comm comm, MPI_Request* request` | Неблокирующее распределение | Для совмещения | — |
| **MPI_Igather** | `void* sendbuf, int sendcount, MPI_Datatype sendtype, void* recvbuf, int recvcount, MPI_Datatype recvtype, int root, MPI_Comm comm, MPI_Request* request` | Неблокирующий сбор | Для совмещения | — |
| **MPI_Iallgather** | `void* sendbuf, int sendcount, MPI_Datatype sendtype, void* recvbuf, int recvcount, MPI_Datatype recvtype, MPI_Comm comm, MPI_Request* request` | Неблокирующий сбор на всех | Для совмещения | — |
| **MPI_Iallreduce** | `void* sendbuf, void* recvbuf, int count, MPI_Datatype datatype, MPI_Op op, MPI_Comm comm, MPI_Request* request` | Неблокирующая редукция на всех | Для совмещения | — |
| **MPI_Ibarrier** | `MPI_Comm comm, MPI_Request* request` | Неблокирующий барьер | Отложенный барьер | — |

### Операции редукции (MPI_Op)

| Операция | Значение | Типы данных |
|----------|----------|-------------|
| `MPI_SUM` | Сумма | Целые, вещественные |
| `MPI_PROD` | Произведение | Целые, вещественные |
| `MPI_MAX` | Максимум | Целые, вещественные |
| `MPI_MIN` | Минимум | Целые, вещественные |
| `MPI_MAXLOC` | Максимум с позицией | Специальные типы |
| `MPI_MINLOC` | Минимум с позицией | Специальные типы |
| `MPI_LAND` | Логическое И | Логические |
| `MPI_LOR` | Логическое ИЛИ | Логические |
| `MPI_LXOR` | Логическое исключающее ИЛИ | Логические |
| `MPI_BAND` | Побитовое И | Целые |
| `MPI_BOR` | Побитовое ИЛИ | Целые |
| `MPI_BXOR` | Побитовое исключающее ИЛИ | Целые |

## 7. Виртуальные топологии

| Функция | Параметры | Что делает | Когда используется | Особенности |
